# Исследование и реализация муравьиного алгоритма для решения задач оптимизации
## Реализовать муравьиный алгоритм для TSP (задача коммивояжера). Приложение должно визуализировать феромонные следы, пути муравьев и лучший маршрут. Предусмотреть настройку параметров: количество муравьев, коэффициент испарения феромона, влияние эвристики
