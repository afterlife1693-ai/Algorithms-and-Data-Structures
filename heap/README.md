## A. Хипуй!

Задача №755.

Реализуйте структуру данных «хип» для хранения целых чисел с операциями:

- `0 k` — добавить в хип число `k` (1 ≤ k ≤ 1 000 000);
- `1` — извлечь и удалить наибольшее число.

### Входные данные

В первой строке задано число команд N (1 ≤ N ≤ 100 000). Далее следуют N команд, каждая на отдельной строке. Гарантируется, что при выполнении извлечения в хипе есть хотя бы один элемент.

### Выходные данные

Для каждой команды извлечения выведите полученное число в отдельной строке.

### Пример

**Входные данные**

```text
2
0 10000
1
```

**Выходные данные**

```text
10000
```

## C. Пирамида (минимум)

Задача №3493.

Обрабатывайте команды над пирамидой, извлекая минимальный элемент:

- `CLEAR` — очистить пирамиду;
- `ADD n` — добавить число n;
- `EXTRACT` — извлечь и вывести минимальное число или `CANNOT`, если пирамида пуста.

### Входные данные

Во входных данных записана последовательность команд, каждая на отдельной строке. Суммарное количество команд не превышает 200 000.

### Выходные данные

Для каждой команды `EXTRACT` выведите результат в отдельной строке.

### Пример

**Входные данные**

```text
ADD 192168812
ADD 125
ADD 321
EXTRACT
EXTRACT
CLEAR
ADD 7
ADD 555
EXTRACT
EXTRACT
EXTRACT
```

**Выходные данные**

```text
125
321
7
555
CANNOT
```

## E. Коммерческий калькулятор

Задача №746.

Калькулятор берет плату за каждую операцию сложения: 5% от результата операции. Найдите минимальную стоимость сложения N заданных натуральных чисел. Стоимость зависит от порядка сложения; оптимальный способ — каждый раз складывать два наименьших числа.

### Входные данные

В первой строке задано N (2 ≤ N ≤ 10⁵). Во второй строке записаны N натуральных чисел, каждое не превосходит 10 000.

### Выходные данные

Выведите минимальную стоимость с двумя знаками после десятичной точки.

### Примеры

**Входные данные**

```text
4
10 11 12 13
```

**Выходные данные**

```text
4.60
```

**Входные данные**

```text
2
1 1
```

**Выходные данные**

```text
0.10
```

## F. Таможня

Задача №1755.

Для каждого груза известны время прибытия и время обработки. Найдите минимальное количество аппаратов, чтобы каждый груз начинали обрабатывать сразу после прибытия. Один аппарат не может обрабатывать два груза одновременно.

### Входные данные

В первой строке задано N (0 ≤ N ≤ 50 000). В следующих N строках записаны два числа Tᵢ и Lᵢ — время прибытия и длительность обработки (1 ≤ Tᵢ, Lᵢ ≤ 10⁶).

### Выходные данные

Выведите минимальное необходимое количество аппаратов.

### Примеры

**Входные данные**

```text
3
3 2
4 2
5 2
```

**Выходные данные**

```text
2
```

**Входные данные**

```text
5
13 4
15 1
11 5
12 3
10 3
```

**Выходные данные**

```text
3
```

## G. Вычислительная ихтиология

Задача №3407.

В лаборатории в ряд стоят n аквариумов. В i-м аквариуме живёт колония из aᵢ рыбок. Достигнув численности f, колония ждёт `max(1000 − f, 1)` секунд до рождения следующей рыбки; такое же время проходит от начального момента до первого рождения.

Лаборант должен фиксировать каждое рождение и перемещается между соседними аквариумами за одну секунду. В начале он стоит у первого аквариума. Найдите момент рождения первой рыбки, которое он не сможет зафиксировать.

### Входные данные

В первой строке задано n (2 ≤ n ≤ 50). Далее в n строках заданы начальные размеры колоний aᵢ (1 ≤ aᵢ ≤ 2007).

### Выходные данные

Выведите время, когда родится рыбка, рождение которой лаборант не сможет зафиксировать.

### Пример

**Входные данные**

```text
3
996
1
994
```

**Выходные данные**

```text
7
```
