# Бинарные деревья поиска

## A. Бинарное дерево (вставка, поиск, удаление)

Задача №3557.

Реализуйте бинарное дерево поиска с операциями:

- `ADD n` — добавить число и вывести `DONE`; если оно уже есть, вывести `ALREADY`;
- `DELETE n` — удалить число и вывести `DONE`; если его нет, вывести `CANNOT`;
- `SEARCH n` — вывести `YES`, если число есть в дереве, иначе `NO`;
- `PRINTTREE` — вывести дерево симметричным обходом: левое поддерево, вершина, правое поддерево. Перед значением каждой вершины выведите по одной точке на каждый уровень её глубины; глубина корня равна нулю.

При удалении вершины с двумя детьми необходимо обменять её значение с максимальным элементом левого поддерева.

### Входные данные

В каждой строке задана одна команда. Всего команд не более 1000, среди них не более 20 команд `PRINTTREE`. При вызове `PRINTTREE` дерево не пусто.

### Выходные данные

Для каждой команды выведите ответ согласно её описанию.

### Пример

**Входные данные**

```text
ADD 2
ADD 7
ADD 5
PRINTTREE
ADD 5
DELETE 3
ADD 0
PRINTTREE
DELETE 7
PRINTTREE
```

**Выходные данные**

```text
DONE
DONE
DONE
2
..5
.7
ALREADY
CANNOT
DONE
.0
2
..5
.7
DONE
.0
2
.5
```

### Пример

```text

```

## K. Следующий

Задача №2782.

Изначально множество целых чисел пусто. Обрабатывайте операции:

- `+ i` — добавить число `i` в множество; если оно уже есть, множество не меняется;
- `? i` — вывести наименьший элемент множества, не меньший `i`, или `-1`, если такого элемента нет.

Если операция `+ i` следует непосредственно за запросом `?`, ответом на который было `y`, вместо `i` добавьте `(i + y) mod 10⁹`. В начале последовательности и после другой операции `+` добавляется само число `i`.

### Входные данные

В первой строке задано количество операций `n` (1 ≤ n ≤ 300 000). В следующих `n` строках записаны операции. Параметры операций лежат в диапазоне от 0 до 10⁹ включительно.

### Выходные данные

Для каждого запроса `?` выведите ответ в отдельной строке.

### Пример

**Входные данные**

```text
6
+ 1
+ 3
+ 3
? 2
+ 1
? 4
```

**Выходные данные**

```text
3
4
```
